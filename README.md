### 𖤐 01 — THE PROJECT

**ULQUIORRA-BOT** is a WhatsApp automation project built with Node.js and Baileys.

Created through experimentation, curiosity, and the constant desire to understand what happens beneath the surface.

More than a collection of commands, this project is a space for development, testing, creativity, and technical exploration.

It is not about building something perfect.

It is about understanding how things work, discovering what can be improved, and turning ideas into something functional.

### ⛓ 02 — THE PHILOSOPHY

> "Not everything that runs is alive. Not everything that breaks is a failure."

Code is structure. Errors are discoveries. Chaos is part of the process.

Every experiment leaves something behind. Every failure reveals something that was previously unseen.

**Build. Experiment. Break. Understand. Rebuild.**

### ☣︎ 03 — TECHNOLOGY

| Technology | Purpose |
|:---|:---|
| Node.js | Runtime environment |
| Baileys | WhatsApp connection and communication |
| JavaScript | Application logic |

### ⚙︎ 04 — GETTING STARTED

Clone the repository:

```bash
git clone (https://github.com/XapaAKT/xapa-bot-main-v1)
```

Enter the project directory:

```bash
cd ULQUIORRA-BOT
```

Install dependencies:

```bash
npm install
```

Configure the required environment and settings, then start the bot using the appropriate project script.
